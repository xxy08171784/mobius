# 技能描述与状态机制待确认清单

> 2026-10-07 更新：本文件保留历史核查/整合记录。A1～A10 已确认并实施，当前规则见 [0.3.0 平衡说明](balance_design_2026-10-07.md)。
核查日期：2026-10-06。范围：5 种初始牌、49 张正式奖励牌、11 种注册状态和勇气资源。

**本文件记录的问题没有擅自改文案、数值或机制。** 本轮已实施的明确需求另见 [UI 更新说明](ui_update_2026-10-06.md)。下面“实际行为”来自当前代码核查，不代表已经确认的策划意图。

## 优先确认

| 编号 | 对象 | 当前描述 / 表现 | 实际行为与影响 | 需要决定 |
|---|---|---|---|---|
| A1 | 疗伤 `card.reward.46` | “抽到手牌就 +3 点生命值恢复效果…（当前 0）” | 每次抽到只累加本张牌的治疗蓄积，3/6/9，打出时才治疗并消耗；“当前 0”不会更新 | 保持蓄积后打出治疗，并显示实时数值，还是改为抽到立即治疗？ |
| A2 | 堆叠防守 `card.reward.37` | “每抽出 1 次护甲 +4（当前 0），打出后重置” | 每次抽到累加 4 点储备护盾；打出才获得护盾并重置。卡面一直写 0 | 建议明确“本牌护盾值 +4”，显示实时储备值，避免误解成抽到即得盾 |
| A3 | 谨慎 `card.reward.03` | “每消耗 1 层获得 2 点护甲（总计?）” | 消耗所有勇气并按 `勇气 × 2` 获得护盾；问号是未替换的占位文字 | 显示当前预计获得量，还是去掉括号？ |
| A4 | 中毒 `status.poison` | “持续时间随后减少” | 每次拥有者回合结束，造成等于层数的伤害、无视护盾，然后层数减 1；并不按持续时间递减 | 改说明匹配当前机制，还是修改衰减方式？ |
| A5 | 禁锢图标对应缠绕 `status.entangle` | “完全无法移动” | 目前仅在玩家回合开始把自然移动点设为 0；冲锋、冲刺、位移效果没有统一禁锢检查。之后获得移动点也可绕过限制；敌人移动路径也未读取缠绕 | 只禁止自然移动，还是禁止所有主动位移？拉拽/击退是否例外？名称统一叫“禁锢”还是“缠绕”？ |
| A6 | 减速 / 钝足 `status.slow` | 状态说明“每层令开局移动力 -1”，卡牌 31 写“钝足” | 玩家按层数扣移动点；敌人只要有该状态就减 1 步，多层不会继续扣 | 统一名称，并决定敌人是否也按层数扣移动 |
| A7 | 眩晕 `status.stun` | “下一次自身行动跳过”，说明里还保留策划占位备注 | 敌人确实跳过行动；玩家输入/回合没有对应眩晕门禁。当前敌人内容未配置对玩家施加眩晕 | 若未来会眩晕玩家，需要确定跳过整回合还是限制部分操作；移除占位备注前确认最终规则 |
| A8 | 正式卡牌升级 | 休息点可以升级；“留一手”也会把抽到的牌等级 +1 | 49 张奖励牌和 5 种初始牌都没有 `upgrade_overrides`；复杂规则也未按升级等级调整数值。所以多数正式卡升级只改等级；复杂牌升级后的悬浮说明可能变空 | 为每张牌设计升级效果，或暂时禁止没有升级效果的牌被升级 |
| A9 | 苦练 `card.reward.26` | “攻击结束后，提升同出的招式牌 3 点攻击力” | 组合结算前就给同出的招式牌 `damage_modifier += 3`，当前这次出牌已获增益，并持续到该战斗结束 | 应从本次生效还是下次生效？是否明确持续至战斗结束？ |
| A10 | 勇气资源 `courage` | 有勇气获得牌和图标，但没有独立状态说明 | 已能获得、保存和被“谨慎”消耗转护盾；伤害管线没有读取勇气，所以不会自动加伤，也没有自然衰减规则 | 如果勇气原本应提高攻击或每回合衰减，需要补设计；当前只能确认资源与转盾用途已实现 |

A8 涉及的“留一手”为 `card.reward.38`，说明“护甲 +5。抽 1 张牌并将其升级”。升级只存在于战斗卡实例，不会写回永久卡组，且代码未给升级次数设限；应一并明确。

## 状态实现核查

没有发现上述 11 种已注册状态完全只有名字、没有任何规则入口。但有些机制只覆盖玩家或敌人的一侧，不能视为全场景完成。

| 状态 / 资源 | 已实现的行为 | 尚待确认或说明不足 |
|---|---|---|
| 流血 | 拥有者回合结束按层数受伤，护盾可抵挡，持续时间递减 | 当前没有明确阻止多实例同时存在；不在本次调整 |
| 中毒 | 按层数受伤、穿盾、每次结算减层 | A4 文案不一致 |
| 着火 | 拥有者回合结束按 `层数 × 5` 受伤、护盾可抵挡、减层 | 文案“火焰”目前没有独立抗性/伤害元素体系，不应暗示已有火抗 |
| 易伤 | 普通伤害修正 +50% | 与虚弱走同一百分比合计，并非先后相乘；要改变算法属于平衡/机制调整 |
| 专注 | 每层普通伤害 +1 | 已实现 |
| 虚弱 | 普通伤害修正 -25% | 同易伤的叠加顺序说明 |
| 腐蚀 | 获得护盾修正 -25% | 已实现 |
| 减速 | 玩家按层数减少开局移动点；敌人减少一步 | A6 两侧算法不同 |
| 缠绕 / 禁锢 | 玩家开局移动点为 0 | A5 尚不是全路径移动禁令 |
| 眩晕 | 敌人跳过行动并执行状态结束结算 | A7 玩家侧未接入 |
| 飞刀标记 | 投掷飞刀留下标记，套索读取并取回 | 已实现；并非独立伤害增益 |
| 勇气 | UnitState 资源，获得/转盾/存档 | A10 未接入伤害与回合衰减 |

提供的新图标覆盖了中毒、着火、眩晕、减速、禁锢、虚弱、勇气。流血、易伤、专注、腐蚀和飞刀标记继续使用旧图集回退；其中旧图集的腐蚀是通用回退图，不是独立美术。**有图标不代表新增了对应机制。**

## 本轮额外发现且已获得确认的问题

原先首次抽牌前没有洗牌，会固定先抽到牌组末尾的 5 张防御。用户已确认修复：新战斗构建时使用 battle RNG 洗牌一次；已开始战斗读档保留手牌、牌堆与 RNG 快照，不重新洗牌。
