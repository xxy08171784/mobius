# 后续制作与发布清单

本轮已处理已知整局 P0 问题，后续重点是持续制作可验证内容并完成实机验收。

## 内容与体验

- AudioCatalog 已接入团队提供的音乐与音效，按钮已统一连接；继续真人试听音量与循环接缝，补充专属怪物/状态音色。详情见 `audio_integration_2026-10-07.md`。
- 补角色头像、新怪物美术、状态图标、背景和卡图，清查动态素材回退。
- 增加角色、遗物和事件，逐项登记、校验并测试中断继续。
- 人工游玩三幕，调胜率、卡池/商店价值、治疗供给与 Boss 强度。
- 翻译所有内容和提示，检查英文长度与混合语言。

## 可继续完善的工程

- 分离 RunFlow 页面控制器，保持规则不回流 UI。
- 新遗物若需逐卡/逐伤害/免死，扩展对应事件钩子与测试；当前通用钩子在命令末触发。
- 章节专属事件、职业掉落、稀有度权重需要扩展定义/选择器，不仅改文件名。
- 发现式图鉴需要接入遭遇记录；当前为全部内容浏览。
- 更完整的响应式 HUD、字体缩放、色弱/触屏支持；当前采用等比留边。
- 按需求增加多存档槽、历史删除/备份导入、云存档；当前只有一个活动局。

## 发布前人工验收

- 真实操作通关/战败，连续游玩数小时，记录卡死、内存与性能。
- 每类节点退出继续，在动画中强制关闭后恢复，确认不重复领钱/奖励。
- Windows 100%/150%/200% DPI、1366×768、16:10、超宽、全屏切换。
- 实体手柄走完所有页面、弹窗与战斗，检查焦点和退出操作。
- 在没有编辑器的另一台电脑运行 exe+pck，验证显卡、字体、声音与存档权限。
- 核对美术/音频/字体授权，补版本号、图标、签名/安装器与商店材料。
- 推送后查看 GitHub Actions；当前只有本地验证结果。

新增机制附与风险匹配的规则/恢复测试；简单视觉编辑做截图和交互检查即可。
