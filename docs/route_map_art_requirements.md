# 选关地图（Route Map）美术需求

项目：GAMEGAM（卡牌 × 战棋 Roguelike，Godot 4.7）。本文是**选关地图界面**的美术素材需求。
风格参考：**《杀戮尖塔》（Slay the Spire）的地图界面**——纵向向上推进的节点图，节点之间连线，底部是起点、顶部是章节 BOSS。

---

## 0. 先确认这两项（影响素材数量）

| 项 | 推荐默认 | 备选 |
|---|---|---|
| **背景**：是否每章不同？ | **每章 1 张，共 3 张**（act1/2/3 风格区分） | 全章通用 1 张 |
| **节点状态**：是否每个状态单独出图？ | **否**——每种类型 1 张图标，未解锁/已访问用暗化+叠加表现（见 §3） | 每状态单独出图（数量 ×4） |

> 下列清单按**推荐默认**列出。若选备选，数量会变，请先确认再开工。

---

## 1. 交付规范（所有素材通用）

| 项 | 要求 |
|---|---|
| 格式 | **PNG，透明底** |
| 色彩空间 | sRGB |
| 尺寸 | 按下方各表；不强制卡死，图标四周**留 4–8px 透明边距**（避免贴边被裁） |
| 命名 | 严格按下方文件名（大小写敏感，全小写+下划线） |
| 存放目录 | `assets/textures/ui/map/`（按下表文件名直接丢进去即自动生效） |
| 交付方式 | 放目录后打包 zip 发我，或直接提 PR |

**关于状态复用**：节点图标只需要**每种类型 1 张**。四种状态（未解锁/可选/已访问/当前）由程序用**变暗、叠加高亮环、叠加标记**表现，不需要各画一张（除非 §0 选了备选）。

## 3. 节点状态如何表现（供美术理解，不用出图）

程序按下表处理外观，美术只需保证图标本身在正常亮度下好看：

| 状态 | 表现 |
|---|---|
| 未解锁（不可去） | 图标压暗 + 可选叠 `node_locked_overlay.png` |
| 可选（能前往） | 正常图标 + 叠 `node_available_glow.png`（呼吸动画） |
| 已访问 | 图标略去色 + 可选打勾（程序做） |
| 当前所在 | 正常图标 + 叠 `node_current_marker.png` |

## 6. 布局参考

地图是**纵向滚动**、由下往上推进。程序按数据摆放节点，美术只需理解大致形态：

```
        [BOSS]              ← 顶部
       /  |  \
    (节点)(节点)(节点)       ← 每层若干节点（约 2–6 个）
      |  \ /  |
    (节点)(节点)(节点)       ← 节点之间连线，路径可汇合
       ...
    (节点)(节点)(节点)       ← 底部第 0 层，玩家从这选一个进场
        ↑ 起点
```

- 单章：15 层 × 7 列 的网格上取约 40–60 个节点。
- 共 **3 章**，形状相同、风格/内容不同 → 同一套组件复用，只有背景和后期内容池不同。
- 建议节点图标视觉直径约 96–128px，层间距约 180–220px；最终间距我会按你给的基准调。
